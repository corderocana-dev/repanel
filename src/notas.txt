1. ¿Qué es un panel sándwich de segunda mano?
Un panel sándwich de segunda mano es un material de construcción que ya ha sido utilizado anteriormente pero que sigue en buenas condiciones para ser reutilizado. Estos paneles ofrecen una alternativa económica y sostenible para diversas aplicaciones.

2. ¿Los paneles sándwich de segunda mano mantienen sus propiedades térmicas y acústicas?
Sí, la mayoría de los paneles sándwich conservan sus propiedades aislantes, aunque puede haber una ligera reducción en el rendimiento en comparación con los nuevos. Antes de la venta, revisamos su estado para garantizar su funcionalidad.

3. ¿De dónde provienen los paneles sándwich de segunda mano?
Estos paneles suelen proceder de desmontajes de naves industriales, almacenes, cámaras frigoríficas y otros tipos de construcciones donde han sido retirados sin sufrir daños importantes.

5. ¿Los paneles sándwich de segunda mano tienen garantía?
Al ser productos reutilizados, no cuentan con la misma garantía que los nuevos, pero ofrecemos una revisión previa para asegurarnos de que cumplen con los estándares de calidad.

Productos.jsx (código):

import React, { useState, useEffect } from "react";
import { useTranslation } from "react-i18next";
import { useParams } from "react-router-dom";
import { FaTimes } from "react-icons/fa";  // Icono de cerrar para el modal
import productosData from "../locals/productos.json";

const Productos = () => {
  const { t } = useTranslation();
  const {categoría} = useParams();
  
  const [isModalOpen, setIsModalOpen] = useState(false);  // Estado para controlar la visibilidad del modal
  const [productos, setProductos] = useState([]);

  useEffect(() => {
    const productosFiltrados = productosData.filter(
      (producto) => producto.categoría === categoría
    );
    // Cargar productos desde el archivo JSON
    setProductos(productosFiltrados);
  }, [categoría]);

  // Función para abrir el modal
  const openModal = () => {
    setIsModalOpen(true);
  };
  // Función para cerrar el modal
  const closeModal = () => {
    setIsModalOpen(false); 
  };

  return (

    <div className="max-w-7xl mx-auto p-4">
      <h1 className="text-2xl font-semibold mb-4">{t('PRODUCTOS')} - {}</h1>
      <p>{t('Bienvenido a nuestra sección de productos')}</p>

      <button
        onClick={openModal}
        className="mt-4 bg-blue-500 text-white px-4 py-2 rounded-lg hover:bg-blue-600"
      >
        {t('Ver Tipos de Productos')}
      </button>

      {isModalOpen && (
        <div className="fixed inset-0 bg-black bg-opacity-50 flex justify-center items-center z-50">
          <div className="bg-white p-6 rounded-lg shadow-lg w-3/4 sm:w-1/2">
            <div className="flex justify-between items-center mb-4">
              <h2 className="text-xl font-semibold">{t('Tipos de Productos')}</h2>
              <button onClick={closeModal}>
                <FaTimes size={20} />
              </button>
            </div>

            <div className="space-y-4">
              {productos.map((producto) => (
                <div key={producto.id} className="border-b py-2">
                  <h3 className="font-semibold">{producto.nombre}</h3>
                  <p>{producto.descripcion}</p>
                </div>
              ))}
            </div>

            <button
              onClick={closeModal}
              className="mt-4 bg-red-500 text-white px-4 py-2 rounded-lg hover:bg-red-600"
            >
              {t('Cerrar')}
            </button>
          </div>
        </div>
      )}
    </div>

  );
};

export default Productos;
